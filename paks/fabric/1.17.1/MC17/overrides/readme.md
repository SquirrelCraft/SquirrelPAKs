# SquirrelPAK MC17


> TL;DR: SquirrelCraft SquirrelPAK Fabulous Squirrels, is low tech Fabric mod pack focused on adventure, exploring, and building with your friends with some life improvement mods.

### Welcome back again fellow Squirrels!

Just as we started MC16, Minecraft 1.17 was released. We wanted to support this as well and since at the time Forge support was lagging behind we took a switch to Fabric. Since there are not as many tech heavy mods out there yet for Fabric this is a low tech adventure mod pack this time around, but with 1.17!


The pack is still in development and mods could be added/removed until we hit Release 1.0 so keep that in mind. 

If create mod lands on fabric for 1.17 that will be added for sure
