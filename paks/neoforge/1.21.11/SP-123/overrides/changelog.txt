Beta 1 

Summary:
Welcome to BETA 1

We have made some tweaks to the options file to
squirrel-a-fi it. 
 - Map button moved to J key
 - F9 to config Jade
 - C key to zoom (must have spy glass) (Changed Zoom Mod)
 - Mini map hidden by default use  \ key to toggle 

Updated mods that had updates

Removed waveycapes due to a bug that was cause a crash
with fancy menu.
