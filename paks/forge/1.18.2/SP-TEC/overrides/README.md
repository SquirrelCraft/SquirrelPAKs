# SquirrelPAK TEC

SquirrelPAK TelEcommuniCations

Oops we did it again, Now that SquirrelPAK AVP has been released, we can now release the third in a line of forge mod packs for 1.18!
 
In this release, SquirrelPAK TEC (TelEcommuniCations) is based off of our AVP pack. We started with AVP then added redstone(Tiny Redstone, TinyGates and others), networking(LaserIO & Xnet) and computers(CC: Tweaked) mods and few others to be a firm foundation for all of our tech mods. Check the wiki for full mod list

Download SquirrelPAK TEC - TelEcommuniCations today and bring advanced redstone, networking, and computers to your Scurry of Server Squirrels today!
